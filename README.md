# Mission Viejo Nadadores — Pool Relay embed preview

A replica of the program pages of [mvnadadores.org](https://www.mvnadadores.org/) with every posted
schedule replaced by a live [Pool Relay](https://www.poolrelay.com) calendar of the Marguerite
Aquatics Complex. Pages are generated: edit `src/<page>.html` and run `python3 build.py`.

## Sources, read 2026-10-08

- **Masters:** the team's SportsEngine workout schedule (Summer/Fall, from August 3), with pool and
  lane counts; pool facts from its Location page.
- **Diving:** mvndiving.com program pages, 2026–2027 regular season.
- **Swim School:** mvnswimschool.org and its Jackrabbit class list (184 classes, Fall 2026,
  October 1 – November 30); Junior Teams and Fall League pages.
- **Facility:** missionviejosports.com (three pools, dive tower) and a 2005 USMS meet page (dive pool
  9 lanes, teaching pool 4 lanes).
- **Events:** mvnadadores.org/events.

Not published, so not on the calendar: Swim Team practices (behind the SportsEngine sign-in), dive
Lessons / High School / Home School times, private lessons. Estimates are marked in each booking's
description and in the page callouts.

Not the official Mission Viejo Nadadores website. Each page says so in a ribbon across the top.
